Задание 1

Будут выведены 14 и 23. В price сохраняется результат вычисления при distance = 4. После присваивания distance = 7 значение price остаётся прежним. Второй print заново вычисляет выражение с текущим расстоянием.

Решение задания 1 (Ответы/01-assignment.py)

distance = 4
price = 3 * distance + 2
distance = 7
print(price)
print(3 * distance + 2)

Результат

14
23

Задание 2

input возвращает строку. При вводе 4 переменная distance хранит текст "4". Умножение 3 * distance повторяет его три раза и даёт строку "444", после чего прибавить число 2 к строке невозможно. Нужно преобразовать введённую запись в число до вычисления. В этом решении предполагается корректный числовой ввод.

Решение задания 2 (Ответы/02-input.py)

text = input("Расстояние в км: ")
distance = float(text)
price = 3 * distance + 2
print("Стоимость:", price)

Пример запуска

Расстояние в км: 4
Стоимость: 14.0

Задание 4

Условия проверяются сверху вниз. После первого истинного условия остальные ветки пропускаются. Если первая проверка ложна, выполняется проверка после elif. Ветка else подходит для оставшегося случая.

Решение задания 4 (Ответы/04-conditions.py)

actual = 8
prediction = 7

if prediction < actual:
    print("Предсказание ниже ответа.")
elif prediction == actual:
    print("Предсказание совпадает с ответом.")
else:
    print("Предсказание выше ответа.")

Результат

Предсказание ниже ответа.

Задание 5

Индекс позволяет выбрать предсказание и известный ответ из одной и той же позиции. Абсолютные ошибки равны 2, 3, 5 и 6. Их сумма равна 16, среднее равно 4.0. Порядок элементов должен соответствовать одним и тем же объектам в обоих списках.

Решение задания 5 (Ответы/05-mae.py)

actuals = [5, 8, 14, 17]
predictions = [3, 5, 9, 11]
errors = []
total_error = 0

for index in range(len(actuals)):
    error = abs(predictions[index] - actuals[index])
    errors.append(error)
    total_error = total_error + error

mae = total_error / len(actuals)
print("Ошибки:", errors)
print("MAE:", mae)

Результат

Ошибки: [2, 3, 5, 6]
MAE: 4.0

Задание 6

Исходный код выводит 4.25. В начале каждого прохода total снова получает 0, поэтому после цикла в нём остаётся только последнее значение 17. Деление 17 на 4 даёт 4.25. Начальное присваивание total = 0 нужно выполнить один раз перед циклом.

Решение задания 6 (Ответы/06-accumulator.py)

prices = [5, 8, 14, 17]
total = 0

for price in prices:
    total = total + price

mean_price = total / len(prices)
print(mean_price)

Результат

11.0

Задание 7

Среднее по обучающим стоимостям равно 11.0. На отложенных примерах постоянное предсказание даёт абсолютные ошибки 0.0 и 9.0, поэтому MAE равна 4.5. Для линейного правила из минипроекта она равна 0.0. Это сравнение относится только к данным нашего учебного примера.

Решение задания 7 (Ответы/07-baseline.py)

train = [[1, 5], [2, 8], [4, 14], [5, 17]]
test = [[3, 11], [6, 20]]

total_price = 0
for sample in train:
    total_price = total_price + sample[1]
baseline = total_price / len(train)

total_error = 0
for sample in test:
    actual = sample[1]
    total_error = total_error + abs(baseline - actual)

test_mae = total_error / len(test)
print("Постоянное предсказание:", baseline)
print("MAE на новых данных:", test_mae)

Результат

Постоянное предсказание: 11.0
MAE на новых данных: 4.5

Задание 8

Сначала сохраняем первый вариант и его ошибку как лучший найденный результат. Затем сравниваем с ним очередной вариант. При меньшей ошибке одновременно обновляем параметры и сохранённую ошибку. Условие использует <, поэтому равная ошибка не заменяет прежний вариант. Проверка на test выполняется после выбора.

Решение задания 8 (Ответы/08-best-rule.py)

def predict(distance, w, b):
    return w * distance + b


def mae(samples, w, b):
    if len(samples) == 0:
        raise ValueError("Нужна хотя бы одна запись.")
    total_error = 0
    for sample in samples:
        prediction = predict(sample[0], w, b)
        total_error = total_error + abs(prediction - sample[1])
    return total_error / len(samples)


train = [[1, 5], [2, 8], [4, 14], [5, 17]]
candidates = [[2, 1], [4, 0], [3, 2]]

best_w = candidates[0][0]
best_b = candidates[0][1]
best_error = mae(train, best_w, best_b)

for candidate in candidates:
    w = candidate[0]
    b = candidate[1]
    error = mae(train, w, b)
    if error < best_error:
        best_w = w
        best_b = b
        best_error = error

test = [[3, 11], [6, 20]]
test_error = mae(test, best_w, best_b)
print("w =", best_w, "b =", best_b)
print("MAE на train:", best_error)
print("MAE на test:", test_error)

Результат

w = 3 b = 2
MAE на train: 0.0
MAE на test: 0.0

Такой перебор нашёл лучшую пару только среди предложенных вариантов по выбранному критерию. Он не проверил все возможные значения параметров. Мы использовали одну заранее выбранную линейную форму; выбор более сложного устройства модели потребует отдельной проверки, о которой пойдёт речь в главе 5.

Задание 9

predict подставляет переданные числа в правило и не обновляет параметры. Обучение потребовало бы отдельной процедуры их подбора. Вызов mae([], 3, 2) из минипроекта вызовет ValueError с сообщением «Нужна хотя бы одна запись». Корректность синтаксиса и успешное выполнение не исключают логических ошибок. Например, программа из задания 6 запускается, но из-за сброса суммы вычисляет другое значение. Нужны проверки на примерах с известным ответом.
