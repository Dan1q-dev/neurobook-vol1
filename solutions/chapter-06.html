Задание 1. Прогноз и два вида ошибки

При w = 2 и b = 3 получаем прогнозы 5, 7 и 9. Разности прогноз минус факт равны 0, -2 и -2. Последние две цены занижены. MAE равна (0 + 2 + 2) / 3 = 4 / 3, MSE равна (0 + 4 + 4) / 3 = 8 / 3. Квадраты увеличивают вклад двух промахов.

Знаковые ошибки, MAE и MSE (Ответы/01-residuals.py)

from statistics import mean

x = [1, 2, 3]
y = [5, 9, 11]
predicted = [2 * value + 3 for value in x]
errors = [a - b for a, b in zip(predicted, y)]
print("Прогнозы", predicted)
print("Ошибки", errors)
print(f"MAE {mean(abs(e) for e in errors):.3f}")
print(f"MSE {mean(e ** 2 for e in errors):.3f}")

Результат

Прогнозы [5, 7, 9]
Ошибки [0, -2, -2]
MAE 1.333
MSE 2.667

Задание 2. Более мелкая сетка смещений

При b = 2 ошибки равны 0, -1 и 0, MSE равна 1 / 3. При b = 2,25 ошибки равны 0,25, -0,75 и 0,25. Сумма квадратов 0,6875, MSE равна 11 / 48, или примерно 0,229167. При b = 2,50 три модуля ошибки равны 0,50, поэтому MSE равна 0,25. Из трёх вариантов выбираем b = 2,25. Точное b = 7 / 3 даёт меньшую MSE, 2 / 9.

Сравнение трёх смещений (Ответы/02-smaller-grid.py)

from statistics import mean

required = [2, 3, 2]
for b in (2, 2.25, 2.50, mean(required)):
    loss = mean((b - value) ** 2 for value in required)
    print(f"b {b:.3f}, MSE {loss:.6f}")

Результат

b 2.000, MSE 0.333333
b 2.250, MSE 0.229167
b 2.500, MSE 0.250000
b 2.333, MSE 0.222222

Задание 3. Новые расстояния и цены

Среднее расстояние равно 3, средняя цена 28 / 3. Отклонения dx равны -2, 0 и 2. Отклонения dy равны -16 / 3, 5 / 3 и 11 / 3. Сумма произведений равна 32 / 3 + 0 + 22 / 3 = 18, сумма dx² равна 4 + 0 + 4 = 8. Вес w = 18 / 8 = 2,25, а b = 28 / 3 - 2,25 × 3 = 31 / 12. При 3 км прогноз равен средней цене 28 / 3.

Суммы отклонений и прогноз (Ответы/03-fit-new-line.py)

from statistics import mean

x = [1, 3, 5]
y = [4, 11, 13]
x_mean, y_mean = mean(x), mean(y)
dx = [value - x_mean for value in x]
dy = [value - y_mean for value in y]
product = sum(a * b for a, b in zip(dx, dy))
squares = sum(value ** 2 for value in dx)
w = product / squares
b = y_mean - w * x_mean

print(f"Средние {x_mean:.3f}, {y_mean:.3f}")
print(f"Суммы {product:.3f}, {squares:.3f}")
print(f"w {w:.3f}, b {b:.3f}, прогноз на 3 км {w * 3 + b:.3f}")

Результат

Средние 3.000, 9.333
Суммы 18.000, 8.000
w 2.250, b 2.583, прогноз на 3 км 9.333

Задание 4. Одинаковые расстояния

На 2 км модель выдаёт одно число 2w + b. Наименьший средний квадрат получается для среднего цен, (6 + 8 + 10) / 3 = 8. Подходят, например, w = 0, b = 8 и w = 3, b = 2. У обеих пар ошибки 2, 0 и -2, MSE равна 8 / 3. В формуле из главы dx равно нулю для всех записей, то есть знаменатель нулевой. Раздельно оценить вес и смещение можно по наблюдениям с разными расстояниями.

Два набора параметров с одним прогнозом (Ответы/04-constant-distance.py)

from statistics import mean

x = [2, 2, 2]
y = [6, 8, 10]
x_mean = mean(x)
total_square = sum((value - x_mean) ** 2 for value in x)
print("Сумма квадратов dx", total_square)
print("Лучший прогноз при 2 км", mean(y))
for w, b in ((0, 8), (3, 2)):
    predicted = [w * value + b for value in x]
    mse = mean((a - b) ** 2 for a, b in zip(predicted, y))
    print("w, b", w, b, "прогнозы", predicted, f"MSE {mse:.3f}")

Результат

Сумма квадратов dx 0
Лучший прогноз при 2 км 8
w, b 0 8 прогнозы [8, 8, 8] MSE 2.667
w, b 3 2 прогнозы [8, 8, 8] MSE 2.667

Задание 5. Новая надбавка за срочность

Разница обычных цен на 3 км и 1 км равна 6, значит, w = 3. Срочная на 1 км стоит 10 вместо 5, поэтому c = 5. Для обычной на 1 км b = 5 - 3 = 2. Для обычной на 4 км получится 3 × 4 + 2 = 14, для срочной добавим 5 и получим 19.

Обучение с изменёнными ценами (Ответы/05-refit-surcharge.py)

from sklearn.linear_model import LinearRegression

X = [[1, 0], [3, 0], [1, 1], [3, 1]]
y = [5, 11, 10, 16]
model = LinearRegression().fit(X, y)
w, c = model.coef_
standard, express = model.predict([[4, 0], [4, 1]])
print(f"w {w:.3f}, c {c:.3f}, b {model.intercept_:.3f}")
print(f"На 4 км, обычная {standard:.3f}, срочная {express:.3f}")

Результат

w 3.000, c 5.000, b 2.000
На 4 км, обычная 14.000, срочная 19.000

Задание 6. Ошибки четырёх заказов

Для заказа 215 расстояние 3 км и обычный тип, поэтому z = 0. Подставляя округлённые коэффициенты, получаем 3,044 × 3 + 1,844 = 10,976. Python использует полную точность и даёт примерно 10,978. Факт равен 12, значит, знаковая ошибка около -1,022. Модули четырёх ошибок равны примерно 1,022, 1,067, 2,933 и 1,111. По неокруглённым значениям MAE около 1,533.

Факт и прогноз по каждому заказу (Ответы/06-test-residuals.py)

import pandas as pd
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_absolute_error

orders = pd.read_csv("orders-quality.csv")
orders["is_express"] = (orders["service"] == "express").astype(int)
train = orders.loc[orders["day"] <= 10]
test = orders.loc[orders["day"] >= 15]
cols = ["distance_km", "is_express"]
model = LinearRegression().fit(train[cols], train["price"])
predicted = model.predict(test[cols])

for order, fact, value in zip(test["order_id"], test["price"], predicted):
    print(f"{order} факт {fact}, прогноз {value:.3f}, ошибка {value-fact:.3f}")
print(f"MAE {mean_absolute_error(test['price'], predicted):.3f}")

Результат

215 факт 12, прогноз 10.978, ошибка -1.022
216 факт 13, прогноз 11.933, ошибка -1.067
217 факт 24, прогноз 21.067, ошибка -2.933
218 факт 19, прогноз 20.111, ошибка 1.111
MAE 1.533

Задание 7. Изменение тестового ответа

Прогноз заказа 217 равен примерно 21,067. И цена 24, и новая цена 34 выше этого прогноза, поэтому модуль ошибки увеличивается ровно на 10. У четырёх заказов среднее увеличится на 10 / 4 = 2,5. Новая MAE около 1,533 + 2,500 = 4,033. Код меняет копию тестовых цен после обучения и подставляет те же прогнозы.

Оценка при исправленном тестовом ответе (Ответы/07-correct-test-price.py)

import pandas as pd
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_absolute_error

orders = pd.read_csv("orders-quality.csv")
orders["is_express"] = (orders["service"] == "express").astype(int)
train = orders.loc[orders["day"] <= 10]
test = orders.loc[orders["day"] >= 15]
cols = ["distance_km", "is_express"]
model = LinearRegression().fit(train[cols], train["price"])
predicted = model.predict(test[cols])
new_price = test["price"].copy()
new_price.loc[test["order_id"] == 217] = 34

old = mean_absolute_error(test["price"], predicted)
new = mean_absolute_error(new_price, predicted)
print(f"MAE до изменения {old:.3f}")
print(f"MAE после изменения {new:.3f}")
print(f"Разница {new - old:.3f}")

Результат

MAE до изменения 1.533
MAE после изменения 4.033
Разница 2.500

Задание 8. Прогноз за пределами обучающих расстояний

Из ручного расчёта w = 3 и b = 7 / 3. На 2 км прогноз равен 6 + 7 / 3 = 25 / 3, около 8,333. На 12 км прогноз равен 36 + 7 / 3 = 115 / 3, около 38,333. Расстояние 2 лежит внутри обучающего диапазона 1-3 км. Для расстояния 12 км продолжаем прямую далеко за его границы. Для проверки нужны фактические цены новых заказов на похожих дальних маршрутах и сведения о том, какие тарифы и условия на них действуют.

Проверка диапазона признака (Ответы/08-distance-range.py)

from sklearn.linear_model import LinearRegression

distance = [1, 2, 3]
X = [[value] for value in distance]
model = LinearRegression().fit(X, [5, 9, 11])
for value in (2, 12):
    predicted = model.predict([[value]])[0]
    inside = min(distance) <= value <= max(distance)
    print(f"{value} км: {predicted:.3f}, внутри диапазона {inside}")

Результат

2 км: 8.333, внутри диапазона True
12 км: 38.333, внутри диапазона False
