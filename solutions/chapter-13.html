Задание 1. Форма и яркость

Делим каждое исходное число на 255. Получаем 0, 0,501961 и 1. У двух изображений форма (2, 1, 28, 28), всего 2 × 1 × 28 × 28 = 1568 элементов. Срез [0, 0, 0, :3] выбирает первые три пикселя нулевой строки первого изображения. Индексы начинаются с нуля.

Три пикселя внутри пакета (Ответы/01-normalize-batch.py)

import torch

pixels = torch.tensor([0, 128, 255], dtype=torch.uint8)
normalized = pixels.float() / 255
images = torch.zeros(2, 1, 28, 28)
images[0, 0, 0, :3] = normalized
print("Яркости", [round(value, 6) for value in normalized.tolist()])
print("Форма пакета", tuple(images.shape))
print("Пикселей в пакете", images.numel())

Результат

Яркости [0.0, 0.501961, 1.0]
Форма пакета (2, 1, 28, 28)
Пикселей в пакете 1568

Задание 2. Проверка выборок

Индексы первого поднабора образуют множество из 54 000 элементов, второго из 6 000. Их пересечение пустое, объединение равно всем индексам от 0 до 59 999. Новое разбиение с тем же начальным состоянием возвращает тот же список train.indices. Список проверяем отдельно, потому что множество сохраняет состав, а порядок теряет.

Пересечение, покрытие и повторяемость (Ответы/02-check-split.py)

from pathlib import Path

train, val = training_sets()
first, second = set(train.indices), set(val.indices)
repeated, _ = training_sets()
print("Размеры", len(first), len(second))
print("Пересечение", len(first & second))
print("Все исходные индексы покрыты", first | second == set(range(60000)))
print("Порядок воспроизведён", train.indices == repeated.indices)

Результат

Все исходные индексы покрыты True

Задание 3. Параметры и формы

После двух пулингов остаётся (3, 16, 7, 7), после Flatten (3, 784), после линейного слоя (3, 10). В первой свёртке 8 × (1 × 3 × 3 + 1) = 80 параметров. Во второй 16 × (8 × 3 × 3 + 1) = 1168. В Linear 10 × (784 + 1) = 7850. В каждой скобке плюс 1 отвечает за смещение. Всего 9098 параметров. Размер пакета не входит в их число.

Размеры пакета и три слоя с весами (Ответы/03-count-parameters.py)

Задание 4. Последний пакет

54 000 = 421 × 128 + 112. Значит, будет 421 полный пакет и один из 112 картинок, всего 422 обновления за эпоху. Во втором расчёте сумма потерь равна 2 × 0,2 + 1 × 0,8 = 1,2. Делим на три объекта и получаем 0,4. Если просто усреднить по пакетам, получится 0,5. Тогда одна картинка из второго пакета получит тот же вес, что две из первого.

Число обновлений и средняя потеря по объектам (Ответы/04-average-batches.py)

full, last = divmod(54000, 128)
sizes = [2, 1]
losses = [0.2, 0.8]
total = sum(size * loss for size, loss in zip(sizes, losses))
print("Полных пакетов", full, "последний размер", last)
print("Шагов", full + int(last > 0))
print(f"Потеря по объектам {total / sum(sizes):.3f}")
print(f"Среднее по пакетам {sum(losses) / len(losses):.3f}")

Результат

Полных пакетов 421 последний размер 112
Шагов 422
Потеря по объектам 0.400
Среднее по пакетам 0.500

Задание 5. Вероятность из десяти логитов

Числитель для класса 0 равен e². В знаменателе e² + 9, потому что экспонента нулевого логита равна 1. Вероятность около 0,450853. Потеря равна минус натуральному логарифму этой величины, около 0,796614. В CrossEntropyLoss подаём исходные логиты и индекс 0. Функция сама вычисляет нужную логарифмическую нормировку.

Кросс-энтропия вручную и в PyTorch (Ответы/05-ten-logits.py)

from math import exp, log
import torch
from torch import nn

logits = torch.tensor([[2.0] + [0.0] * 9], dtype=torch.float64)
target = torch.tensor([0])
manual = exp(2) / (exp(2) + 9)
criterion = nn.CrossEntropyLoss()
loss = criterion(logits, target).item()
print(f"По формуле {manual:.6f}")
print(f"Softmax {logits.softmax(1)[0, 0].item():.6f}")
print(f"Потеря вручную {-log(manual):.6f}, в PyTorch {loss:.6f}")

Результат

По формуле 0.450853
Softmax 0.450853
Потеря вручную 0.796614, в PyTorch 0.796614

Задание 6. Полнота и точность для семёрки

Диагональная клетка [7, 7] равна 1001. Сумма строки 7 равна 1028, это все настоящие семёрки. Сумма столбца 7 равна 1044, это все прогнозы «7». Полнота равна 1001 / 1028 ≈ 97,37%, precision равна 1001 / 1044 ≈ 95,88%. В обе дроби входит число верных прогнозов класса 7.

Одна клетка и две суммы (Ответы/06-recall-and-precision.py)

import json
from pathlib import Path

table = json.loads(Path("mnist-test.json").read_text(encoding="utf-8"))["confusion"]
digit = 7
true_positive = table[digit][digit]
actual = sum(table[digit])
predicted = sum(row[digit] for row in table)
print("Верные семёрки", true_positive)
print("Настоящих семёрок", actual, "прогнозов семёрки", predicted)
print(f"Полнота {100 * true_positive / actual:.2f}%")
print(f"Точность класса {100 * true_positive / predicted:.2f}%")

Результат

Верные семёрки 1001
Настоящих семёрок 1028 прогнозов семёрки 1044
Полнота 97.37%
Точность класса 95.88%

Задание 7. Прогноз по самому частому классу

Чаще всего в обучении встречалась цифра 1, у неё 6046 примеров. Прогнозируя этот класс на всех картинках, получим столько верных ответов, сколько таких картинок в тесте. Сумма строки 1 равна 1135. Базовая точность 11,35%. Разница с сетью составляет 86,35 процентного пункта. Класс выбирали по обучающей части.

Сравнение с постоянным прогнозом (Ответы/07-majority-baseline.py)

import json
from pathlib import Path
import sys
import torch

sys.path.insert(0, str(Path(__file__).resolve().parents[1] / "Примеры"))
from digit_data import training_sets

train, _ = training_sets()
counts = torch.bincount(train.dataset.targets[train.indices], minlength=10)
majority = counts.argmax().item()
result = json.loads(Path("mnist-test.json").read_text(encoding="utf-8"))
baseline = sum(result["confusion"][majority])
total = result["examples"]
print("Частый класс в train", majority, "картинок", counts[majority].item())
print(f"Базовая точность {baseline}/{total} = {100 * baseline / total:.2f}%")
print(f"Разница {100 * (result['correct'] - baseline) / total:.2f} п. п.")

Результат

Частый класс в train 1 картинок 6046
Базовая точность 1135/10000 = 11.35%
Разница 86.35 п. п.

Задание 8. Проверка на сдвиг

При shift = 4 копируем столбцы 0-23 в 4-27. Слева остаются нули. nonzero находит изменившиеся ответы. У индекса 2 при метке 1 прогноз меняется с 1 на 4. to_pil_image готовит тензоры к сохранению в два файла.

parents[1] даёт папку главы. Так подключаем «Примеры», как в главе 11. Три двоеточия сохраняют все изображения, каналы и строки. Последний срез выбирает столбцы для сдвига.

Те же метки после сдвига цифр (Ответы/08-shift-test-digits.py)

from pathlib import Path
import sys
import torch
from torchvision.transforms.functional import to_pil_image

sys.path.insert(0, str(Path(__file__).resolve().parents[1] / "Примеры"))
from digit_data import load_digits
from digit_model import load_model

torch.set_num_threads(4)
test = load_digits(train=False)
X = torch.stack([test[i][0] for i in range(256)])
y = test.targets[:256]
shift = 4
shifted = torch.zeros_like(X)
if shift > 0:
    shifted[:, :, :, shift:] = X[:, :, :, :-shift]
elif shift < 0:
    shifted[:, :, :, :shift] = X[:, :, :, -shift:]
else:
    shifted = X.clone()

model, _ = load_model()
with torch.inference_mode():
    before = model(X).argmax(dim=1)
    after = model(shifted).argmax(dim=1)
for name, predictions in (("Исходные", before), ("Сдвинутые", after)):
    correct = (predictions == y).sum().item()
    print(f"{name}: {correct}/{len(y)}, {100 * correct / len(y):.2f}%")

changed = (before != after).nonzero(as_tuple=True)[0]
if changed.numel():
    i = changed[0].item()
    print(f"Индекс {i}, метка {y[i]}, прогнозы {before[i]} и {after[i]}")
    to_pil_image(X[i]).save("цифра-до.png")
    to_pil_image(shifted[i]).save("цифра-после.png")
else:
    print("Прогнозы совпадают")

Результат

Исходные: 255/256, 99.61%
Сдвинутые: 155/256, 60.55%
Индекс 2, метка 1, прогнозы 1 и 4
