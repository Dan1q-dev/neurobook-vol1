Задание 1. Прямой проход для заказа 301

Первая сумма равна 0,5 × 0,5 + 1 × 0 - 1 = -0,75. Вторая равна -0,5 × 0,5 - 0,5 × 0 + 0,5 = 0,25. После ReLU получаем 0 и 0,25. Выходная оценка z = 0 × 1 + 0,25 × (-1) - 1 = -1,25. Вероятность опоздания около 0,222700. Факт равен 0, поэтому вероятность правильного класса равна 1 - p, а потеря около 0,251929.

Скрытые значения и вероятность (Ответы/01-second-order.py)

import numpy as np

x = np.array([0.5, 0.0])
W = np.array([[0.5, -0.5], [1.0, -0.5]])
b, v = np.array([-1.0, 0.5]), np.array([1.0, -1.0])
s = x @ W + b
h = np.maximum(s, 0)
z = h @ v - 1
p = 1 / (1 + np.exp(-z))
loss = np.logaddexp(0, z)
print("s", s.tolist(), "h", h.tolist())
print(f"z {z:.6f}, p {p:.6f}, потеря {loss:.6f}")

Результат

s [-0.75, 0.25] h [0.0, 0.25]
z -1.250000, p 0.222700, потеря 0.251929

Задание 2. Две суммы без ReLU

Вычисляем (x @ W + b) · v + c. После раскрытия скобок коэффициенты при входах равны W @ v. Для x₁ это 0,5 × 1 + (-0,5) × (-1) = 1, для x₂ это 1 × 1 + (-0,5) × (-1) = 1,5. Свободный член равен b · v + c = -1 - 0,5 - 1 = -2,5. Для заказа 307 получаем z = 2 + 1,5 - 2,5 = 1. С ReLU вторая скрытая сумма превращается в ноль и выходная оценка равна 0.

Сравнение оценок z (Ответы/02-collapse-layers.py)

import numpy as np

x = np.array([2.0, 1.0])
W = np.array([[0.5, -0.5], [1.0, -0.5]])
b, v = np.array([-1.0, 0.5]), np.array([1.0, -1.0])
c = -1.0
weight, bias = W @ v, b @ v + c
direct = x @ weight + bias
two_sums = (x @ W + b) @ v + c
with_relu = np.maximum(x @ W + b, 0) @ v + c
print("Общий вес", weight.tolist(), "смещение", bias)
print("Одна сумма", direct, "две суммы", two_sums)
print("С ReLU", with_relu)

Результат

Общий вес [1.0, 1.5] смещение -2.5
Одна сумма 1.0 две суммы 1.0
С ReLU 0.0

Задание 3. Другая метка и направление градиента

Входы и параметры сохранились, поэтому p = 0,5. При y = 0 производная по z равна 0,5. Производная по v₁ равна 0,5, по v₂ ноль, по c равна 0,5. Производные по h равны 0,5 и -0,5. ReLU пропускает только первый вклад. Значит, в первом столбце dW стоят 1 и 0,5, второй столбец нулевой. Для b получаем 0,5 и 0. Ненулевые градиенты имеют противоположный знак относительно примера с y = 1.

Градиенты при y = 0 (Ответы/03-switch-label.py)

import numpy as np

x = np.array([2.0, 1.0])
W = np.array([[0.5, -0.5], [1.0, -0.5]])
b, v = np.array([-1.0, 0.5]), np.array([1.0, -1.0])
s = x @ W + b
h = np.maximum(s, 0)
z = h @ v - 1
dz = 1 / (1 + np.exp(-z)) - 0
ds = np.where(s > 0, v * dz, 0.0)
print("dz", dz)
print("dW", np.outer(x, ds).tolist(), "db", ds.tolist())
print("dv", (h * dz).tolist(), "dc", dz)

Результат

dz 0.5
dW [[1.0, 0.0], [0.5, 0.0]] db [0.5, 0.0]
dv [0.5, 0.0] dc 0.5

Задание 4. Шаг со скоростью 0,20

Градиенты исходной точки известны. У первого нейрона первый вес растёт с 0,5 до 0,7, второй с 1 до 1,1, смещение с -1 до -0,9. Первый выходной вес становится 1,1, выходное смещение -0,9. Второй скрытый нейрон и его выходной вес остаются прежними, поскольку их градиенты нулевые. Новая сумма s₁ = 2 × 0,7 + 1,1 - 0,9 = 1,6. Выходная оценка z = 1,6 × 1,1 - 0,9 = 0,86, p ≈ 0,702661, потеря около 0,352881.

Подстановка после шага (Ответы/04-step-point-two.py)

import numpy as np

x = np.array([2.0, 1.0])
W = np.array([[0.5, -0.5], [1.0, -0.5]])
b, v = np.array([-1.0, 0.5]), np.array([1.0, -1.0])
c, rate = -1.0, 0.2
dW = np.array([[-1.0, 0.0], [-0.5, 0.0]])
db, dv, dc = np.array([-0.5, 0.0]), np.array([-0.5, 0.0]), -0.5
W, b = W - rate * dW, b - rate * db
v, c = v - rate * dv, c - rate * dc
s = x @ W + b
z = np.maximum(s, 0) @ v + c
p = 1 / (1 + np.exp(-z))
print("W", W.round(2).tolist(), "b", b.round(2).tolist())
print("v", v.round(2).tolist(), f"c {c:.2f}")
print(f"s1 {s[0]:.6f}, z {z:.6f}, p {p:.6f}")
print(f"Потеря {np.logaddexp(0, -z):.6f}")

Результат

W [[0.7, -0.5], [1.1, -0.5]] b [-0.9, 0.5]
v [1.1, -1.0] c -0.90
s1 1.600000, z 0.860000, p 0.702661
Потеря 0.352881

Задание 5. Граница активации

Изначально s₂ = -1. Сдвиги ±0,01 дают -0,99 и -1,01. В обоих случаях h₂ = 0, z = 0 и потери равны, поэтому численная производная равна нулю. При сдвиге на 1,10 сумма s₂ станет 0,10. Второй нейрон включится, его вклад в z будет 0,10 × (-1) = -0,10. Потеря вырастет до ln(1 + exp(0,10)) ≈ 0,744397. Производная в исходной точке описывает изменение лишь в её окрестности.

Малое и большое изменение смещения (Ответы/05-relu-boundary.py)

from math import exp, log1p

def loss(shift):
    second = max(0, -1 + shift)
    z = 1 - second - 1
    return log1p(exp(-z))

eps = 0.01
slope = (loss(eps) - loss(-eps)) / (2 * eps)
print(f"Потери рядом {loss(-eps):.6f} и {loss(eps):.6f}")
print(f"Производная {slope:.6f}")
print(f"Потеря при сдвиге 1,10 {loss(1.10):.6f}")

Результат

Потери рядом 0.693147 и 0.693147
Производная 0.000000
Потеря при сдвиге 1,10 0.744397

log1p(t) вычисляет ln(1 + t). В этом решении изменяем только второй скрытый нейрон, поэтому его активация вычитается из прежнего z = 0. Вес этой связи равен -1.

Задание 6. Сложение вкладов двух ветвей

Первая ветвь даёт 2 × (-0,4) = -0,8. Вторая даёт (-3) × 0,1 = -0,3. Производная по общему h равна сумме -1,1. При s = 0,6 ReLU имеет наклон 1, поэтому производная по s равна -1,1. При s = -0,6 наклон 0 и производная равна 0.

От ветвей к скрытой сумме (Ответы/06-two-paths.py)

weights, downstream = [2, -3], [-0.4, 0.1]
parts = [a * b for a, b in zip(weights, downstream)]
dh = sum(parts)
print(f"Вклады {parts[0]:.1f} и {parts[1]:.1f}, сумма {dh:.1f}")
for s in (0.6, -0.6):
    ds = dh if s > 0 else 0.0
    print(f"s {s:.1f}, производная {ds:.1f}")

Результат

Вклады -0.8 и -0.3, сумма -1.1
s 0.6, производная -1.1
s -0.6, производная 0.0

Задание 7. Один вес и два заказа

У заказа 307 второй скрытый нейрон неактивен, его вклад нулевой. У заказа 301 производная по z с учётом среднего равна p/2, поскольку y = 0. Вес от второго нейрона к выходу равен -1, а наклон ReLU равен 1. Значит, производная по второй скрытой сумме равна -p/2. Умножаем на x₁ = 0,5 и получаем вклад -p/4 ≈ -0,055675. Это первая строка и второй столбец dW.

Проверка вклада каждой строки (Ответы/07-weight-contributions.py)

import numpy as np

X = np.array([[2.0, 1.0], [0.5, 0.0]])
y = np.array([1.0, 0.0])
W = np.array([[0.5, -0.5], [1.0, -0.5]])
b, v = np.array([-1.0, 0.5]), np.array([1.0, -1.0])
S = X @ W + b
z = np.maximum(S, 0) @ v - 1
p = 1 / (1 + np.exp(-z))
dz = (p - y) / len(y)
dS = np.where(S > 0, dz[:, None] * v, 0.0)
parts = X[:, 0] * dS[:, 1]
dW = X.T @ dS
print("Вклады", parts.round(6).tolist())
print("Матрица", dW.round(6).tolist())

Результат

Вклады [0.0, -0.055675]
Матрица [[-0.5, -0.055675], [-0.25, 0.0]]

Задание 8. Другая метка в пакете

Прямой проход оставляет вероятности 0,5 и 0,222700 при тех же параметрах. Для заказа 301 теперь берём -ln(p) ≈ 1,501929. Его потеря увеличилась на 1,25, а средняя на 1,25 / 2 = 0,625 и стала примерно 1,097538. Градиент веса от x₁ ко второму нейрону равен -(p - 1)/4 ≈ 0,194325. Раньше он был отрицательным. Изменилась метка, поэтому обучение теперь толкает прогноз второго заказа в другую сторону.

Потеря и градиент до и после смены метки (Ответы/08-batch-label.py)

import numpy as np

z = np.array([0.0, -1.25])
p = 1 / (1 + np.exp(-z))
for y in (np.array([1.0, 0.0]), np.array([1.0, 1.0])):
    loss = np.logaddexp(0, (1 - 2 * y) * z).mean()
    dz = (p - y) / len(y)
    gradient = 0.5 * (-1) * dz[1]
    print(f"Метка 301 {y[1]:.0f}, потеря {loss:.6f}")
    print(f"Градиент выбранного веса {gradient:.6f}")

Результат

Метка 301 0, потеря 0.472538
Градиент выбранного веса -0.055675
Метка 301 1, потеря 1.097538
Градиент выбранного веса 0.194325
