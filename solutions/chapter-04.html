Задание 1. Три действия с векторами

В сумме получаем (2 + (-1), -1 + 3) = (1, 2). При вычитании первой компоненты имеем 2 - (-1) = 3, при вычитании второй -1 - 3 = -4. При умножении v на -2 получаем (-2) × (-1) = 2 и (-2) × 3 = -6. Два минуса в первом произведении дают плюс.

Сверка операций по компонентам (Ответы/01-vector-arithmetic.py)

import numpy as np

u = np.array([2, -1])
v = np.array([-1, 3])

print("u + v", (u + v).tolist())
print("u - v", (u - v).tolist())
print("(-2) * v", (-2 * v).tolist())

Результат

u + v [1, 2]
u - v [3, -4]
(-2) * v [2, -6]

Задание 2. Одно произведение и одно расстояние

Скалярное произведение равно 1 × 3 + 2 × 4 = 11. Для расстояния сначала вычисляем смещение v - u = (3 - 1, 4 - 2) = (2, 2). Его длина равна √(2² + 2²) = √8, приблизительно 2,828. Если вычесть точки в обратном порядке, изменятся знаки компонент разности. После возведения в квадрат сумма останется равной 8.

Длина разности векторов (Ответы/02-distance.py)

import numpy as np

u = np.array([1, 2])
v = np.array([3, 4])
difference = v - u

print("Произведение", u @ v)
print("Разность", difference.tolist())
print("Расстояние", round(np.linalg.norm(difference), 3))

Результат

Произведение 11
Разность [2, 2]
Расстояние 2.828

Задание 3. Строка становится столбцом

Второй заказ имеет признаки (1, 4), поэтому X[1, 1] равно 4. После транспонирования в первой строке стоят расстояния (3, 1, 2), во второй массы (2, 4, 1). Компоненты второго заказа теперь занимают второй столбец. Размер меняется с 3 × 2 на 2 × 3.

Индексация до и после .T (Ответы/03-transpose.py)

import numpy as np

X = np.array([[3, 2], [1, 4], [2, 1]])
print("Формы", X.shape, X.T.shape)
print("X[1, 1]", X[1, 1])
print("Вторая строка X", X[1].tolist())
print("Второй столбец X.T", X.T[:, 1].tolist())

Результат

Формы (3, 2) (2, 3)
X[1, 1] 4
Вторая строка X [1, 4]
Второй столбец X.T [1, 4]

Задание 4. Произведение прямоугольных матриц

У A две строки по три элемента, у B три строки по два элемента. Для A @ B общий размер равен 3. Умножим первую строку A на два столбца B. Получим 2 × 1 + 1 × 0 + 0 × 2 = 2 и 2 × 2 + 1 × 1 + 0 × 0 = 5. Для второй строки суммы равны 1 × 1 + 3 × 0 + 2 × 2 = 5 и 1 × 2 + 3 × 1 + 2 × 0 = 5. Получилась матрица со строками [2, 5] и [5, 5]. В произведении B @ A общий размер равен 2, поэтому результат имеет форму (3, 3).

Расчёт A @ B

Первая строка    2 × 1 + 1 × 0 + 0 × 2 = 2
                 2 × 2 + 1 × 1 + 0 × 0 = 5
Вторая строка    1 × 1 + 3 × 0 + 2 × 2 = 5
                 1 × 2 + 3 × 1 + 2 × 0 = 5

Размеры в обоих порядках (Ответы/04-rectangular-product.py)

import numpy as np

A = np.array([[2, 1, 0], [1, 3, 2]])
B = np.array([[1, 2], [0, 1], [2, 0]])
AB = A @ B
BA = B @ A
print("A @ B", AB.shape, AB.tolist())
print("B @ A", BA.shape, BA.tolist())

Результат

A @ B (2, 2) [[2, 5], [5, 5]]
B @ A (3, 3) [[4, 7, 4], [1, 3, 2], [4, 2, 0]]

Задание 5. Новые веса цены

Для первого заказа получаем 3 × 4 + 2 × 1 + 2 = 16. Для второго 1 × 4 + 4 × 1 + 2 = 10. Для третьего 2 × 4 + 1 × 1 + 2 = 11. Число выходов на заказ равно одному, поэтому итоговый одномерный массив имеет три элемента.

Задание 6. Смещение времени

Для третьего заказа (2, 1) цена равна 2 × 3 + 1 × 2 + 5 = 13, время равно 2 × 5 + 1 × 1 + 8 = 19. Замена смещения времени на 10 добавляет 2 минуты во второй столбец каждой строки. Например, для третьего заказа получим пару (13, 21).

Какой выход изменился (Ответы/06-new-bias.py)

import numpy as np

X = np.array([[3, 2], [1, 4], [2, 1]])
W = np.array([[3, 5], [2, 1]])
old = X @ W + np.array([5, 8])
new = X @ W + np.array([5, 10])

print("Третий заказ", old[2].tolist())
print("Новый прогноз", new.tolist())
print("Разность", (new - old).tolist())

Результат

Третий заказ [13, 19]
Новый прогноз [[18, 27], [16, 19], [13, 21]]
Разность [[0, 2], [0, 2], [0, 2]]

Задание 7. Форма и смысл весов

У произведения X @ W в каждой строке два выхода. Массив b длины 3 содержит три значения для двух мест. Для наших форм NumPy сравнит размеры справа, 2 и 3, и выдаст ValueError. Исправление для этого примера состоит в выборе двух смещений, [5, 8].

Первая колонка W.T содержит 3 и 5. С ней цена первого заказа получится 3 × 3 + 2 × 5 + 5 = 24. Вторая колонка содержит 2 и 1, поэтому время будет 3 × 2 + 2 × 1 + 8 = 16. У правильной W прогноз равен (18, 25). Формы совпадают, поскольку матрица квадратная. Ошибка обнаруживается при проверке того, какие веса отнесены к каждому выходу.

Смещения и порядок весов (Ответы/07-shape-and-order.py)

import numpy as np

X = np.array([[3, 2], [1, 4], [2, 1]])
W = np.array([[3, 5], [2, 1]])
b = np.array([5, 8])
try:
    X @ W + np.array([5, 8, 10])
except ValueError:
    print("Для двух выходов нужны два смещения")

print("С W", (X @ W + b)[0].tolist())
print("С W.T", (X @ W.T + b)[0].tolist())

Результат

Для двух выходов нужны два смещения
С W [18, 25]
С W.T [24, 16]

Задание 8. Новый заказ для слоя

Для заказа 110 цена равна 0,6 × 10 + 5 × 1 + 0 × 0 + 1 × 3 + 4 = 18. Время равно 0,6 × 20 + 5 × 0 + 0 × 0 + 1 × (-5) + 12 = 19 минут. В X теперь четыре строки по четыре признака, в Y четыре строки по два выхода. Заказ 110 стоит третьим, поэтому для его результата берём Y[2].

Четыре заказа на входе (Ответы/08-add-order.py)

import numpy as np

X = np.array([
    [0.4, 3.0, 1, 0],
    [1.4, 2.5, 0, 1],
    [0.6, 5.0, 0, 1],
    [1.0, 0.5, 1, 0],
])
W = np.array([[10, 20], [1, 0], [0, 0], [3, -5]])
b = np.array([4, 12])
Y = X @ W + b

print("Формы X и Y", X.shape, Y.shape)
print("Заказ 110", Y[2].round(1).tolist())

Результат

Формы X и Y (4, 4) (4, 2)
Заказ 110 [18.0, 19.0]
