Задание 1. Три разных знаменателя

Среди 12 коротких заказов опоздали 2, поэтому условная вероятность равна 2/12 = 1/6. Среди 6 опозданий короткими были 2, поэтому обратная условная вероятность равна 2/6 = 1/3. Среди 8 дальних заказов к сроку приехали 4, вероятность равна 4/8 = 1/2.

Условие задаёт знаменатель (Ответы/01-conditional.py)

short_late = 2
short_total, all_late = 12, 6
long_on_time, long_total = 4, 8
print(f"Опоздание среди коротких {short_late / short_total:.4f}")
print(f"Короткий среди опозданий {short_late / all_late:.4f}")
print(f"Вовремя среди дальних {long_on_time / long_total:.4f}")

Результат

Опоздание среди коротких 0.1667
Короткий среди опозданий 0.3333
Вовремя среди дальних 0.5000

Задание 2. Две стороны сигмоиды

На 1 км z = -3 и p = 1 / (1 + exp(3)) ≈ 0,047426. На 7 км z = 3 и p ≈ 0,952574. Вероятности дополняют друг друга до 1. Сигмоида возрастает и равна 0,5 при z = 0, поэтому при t = 0,5 класс 1 начинается с x = 4 км, включая саму границу.

Дальности по обе стороны порога (Ответы/02-symmetric-sigmoid.py)

from math import exp

for distance in (1, 4, 7):
    z = distance - 4
    p = 1 / (1 + exp(-z))
    label = int(p >= 0.5)
    print(f"{distance} км, z {z}, p {p:.6f}, класс {label}")

Результат

1 км, z -3, p 0.047426, класс 0
4 км, z 0, p 0.500000, класс 1
7 км, z 3, p 0.952574, класс 1

Задание 3. Уверенность и потеря

При y = 1 потери равны -ln(0,9) ≈ 0,105361 и -ln(0,6) ≈ 0,510826. При y = 0 считаем -ln(0,1) ≈ 2,302585 и -ln(0,4) ≈ 0,916291. При пороге 0,5 оба прогноза дают класс 1. Вероятность 0,9 получает меньшую потерю при опоздании и большую, когда заказ прибывает к сроку.

Четыре значения log loss (Ответы/03-compare-losses.py)

from math import log

for y in (1, 0):
    for p in (0.9, 0.6):
        correct = p if y == 1 else 1 - p
        label = int(p >= 0.5)
        print(f"y {y}, p {p:.1f}, класс {label}, потеря {-log(correct):.6f}")

Результат

y 1, p 0.9, класс 1, потеря 0.105361
y 1, p 0.6, класс 1, потеря 0.510826
y 0, p 0.9, класс 1, потеря 2.302585
y 0, p 0.6, класс 1, потеря 0.916291

Задание 4. Шаг со скоростью 0,5

В начальной точке обе вероятности 0,5, поэтому разности p - y равны 0,5 и -0,5. Производные остаются dw = -0,5 и db = 0. После умножения на скорость получаем w = 0 - 0,5 × (-0,5) = 0,25 и b = 0. Оценки z равны -0,25 и 0,25. Вероятности класса 1 равны примерно 0,437823 и 0,562177. Для обоих заказов вероятность правильного класса 0,562177, средняя потеря около 0,575939.

Меньший шаг обновления (Ответы/04-step-at-half.py)

from math import exp, log
from statistics import mean

x, y = [-1, 1], [0, 1]
errors = [0.5 - label for label in y]
dw = mean(error * a for error, a in zip(errors, x))
db = mean(errors)
w, b = 0.0, 0.0
w, b = w - 0.5 * dw, b - 0.5 * db
p = [1 / (1 + exp(-(w * a + b))) for a in x]
loss = -mean(log(value if label else 1 - value)
             for value, label in zip(p, y))
print(f"w {w:.3f}, b {b:.3f}")
print("Вероятности", [round(value, 6) for value in p])
print(f"Средняя потеря {loss:.6f}")

Результат

w 0.250, b 0.000
Вероятности [0.437823, 0.562177]
Средняя потеря 0.575939

Задание 5. Порог 0,65

Предупреждения получат заказы с вероятностями 0,85, 0,72 и 0,65. Фактически опоздали два из них, с p = 0,85 и p = 0,65. Итог TN = 4, FP = 1, FN = 1, TP = 2. Precision равна 2/3 и recall тоже 2/3. Верных ответов 6 из 8, accuracy равна 0,75. Заказ на границе 0,65 входит в число предупреждений.

Проверка равенства порогу (Ответы/05-equal-threshold.py)

p = [0.85, 0.72, 0.65, 0.55, 0.40, 0.32, 0.20, 0.10]
y = [1, 0, 1, 0, 1, 0, 0, 0]
decisions = [int(value >= 0.65) for value in p]
matrix = [[0, 0], [0, 0]]
for fact, label in zip(y, decisions):
    matrix[fact][label] += 1
tn, fp = matrix[0]
fn, tp = matrix[1]
print("Предупреждений", sum(decisions), "подтвердились", tp)
print("TN FP FN TP", tn, fp, fn, tp)
print(f"precision {tp / (tp + fp):.4f}, recall {tp / (tp + fn):.4f}")
print(f"accuracy {(tn + tp) / len(y):.4f}")

Результат

Предупреждений 3 подтвердились 2
TN FP FN TP 4 1 1 2
precision 0.6667, recall 0.6667
accuracy 0.7500

Задание 6. Другая цена ошибок

Новая формула цены равна 2 × FP + FN. Для t = 0,30 получаем 2 × 3 + 0 = 6. Для t = 0,50 получаем 2 × 2 + 1 = 5. Для t = 0,70 получаем 2 × 1 + 2 = 4. Наименьшая цена среди трёх порогов теперь при t = 0,70. Вероятности и факты те же, а оценка последствий ошибок изменилась.

Выбор при новой цене (Ответы/06-new-error-prices.py)

counts = {0.30: (3, 0), 0.50: (2, 1), 0.70: (1, 2)}
costs = {}
for threshold, (fp, fn) in counts.items():
    costs[threshold] = 2 * fp + fn
    print(f"Порог {threshold:.2f}, цена {costs[threshold]}")
chosen = min(costs, key=costs.get)
print(f"Выбранный порог {chosen:.2f}")

Результат

Порог 0.30, цена 6
Порог 0.50, цена 5
Порог 0.70, цена 4
Выбранный порог 0.70

Задание 7. Средние прогнозы и доли

Средняя вероятность в первой группе равна 1,0 / 5 = 0,2, фактическая доля 2/5 = 0,4. В этой группе прогнозы ниже доли на 0,2. Во второй среднее 3,5 / 5 = 0,7, доля 3/5 = 0,6. Средняя вероятность выше доли на 0,1. В каждой группе всего пять наблюдений, поэтому разницу полезно перепроверить на более крупном наборе.

Две группы по пять заказов (Ответы/07-check-calibration.py)

from statistics import mean

groups = (([0.1, 0.2, 0.3, 0.2, 0.2], 2),
          ([0.6, 0.7, 0.8, 0.7, 0.7], 3))
for number, (p, late) in enumerate(groups, start=1):
    average = mean(p)
    observed = late / len(p)
    print(f"{number}: среднее p {average:.2f}, доля {observed:.2f}")

Результат

1: среднее p 0.20, доля 0.40
2: среднее p 0.70, доля 0.60

Задание 8. Сравнение с одной вероятностью

В train 10 опозданий из 20, поэтому базовая вероятность 0,5. При t = 0,30 базовое правило предупреждает о всех восьми тестовых заказах. Оно находит три опоздания и даёт пять ложных предупреждений, цена равна 5. Вероятность факта всегда 0,5, так что log loss равна -ln(0,5) ≈ 0,693147. Модель даёт цену 3 и log loss около 0,669828. Цена оценивает действия при выбранном пороге, log loss оценивает вероятности по фактическим ответам. Разница посчитана на восьми учебных заказах.

Две проверки на одних заказах (Ответы/08-constant-baseline.py)

import pandas as pd
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import confusion_matrix, log_loss

orders = pd.read_csv("orders-late.csv")
train = orders.loc[orders["day"] <= 20]
test = orders.loc[orders["day"] >= 29]
cols = ["distance_km", "rush"]
model = LogisticRegression(max_iter=1000).fit(train[cols], train["late"])
actual = test["late"]
base = train["late"].mean()
print(f"Базовая вероятность {base:.6f}")
candidates = (("Модель", model.predict_proba(test[cols])[:, 1]),
              ("База", [base] * len(test)))
for name, p in candidates:
    labels = [int(value >= 0.30) for value in p]
    tn, fp, fn, tp = confusion_matrix(actual, labels, labels=[0, 1]).ravel()
    price = fp + 5 * fn
    loss = log_loss(actual, p, labels=[0, 1])
    print(f"{name}: цена {price}, log loss {loss:.6f}")

Результат

Базовая вероятность 0.500000
Модель: цена 3, log loss 0.669828
База: цена 5, log loss 0.693147
