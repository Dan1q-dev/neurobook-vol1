Задание 1. Новые коэффициенты

Для расстояний 1, 2, 4 и 5 получаем 4, 8, 16 и 20. Абсолютные разности с ценами 5, 8, 14 и 17 равны 1, 0, 2 и 3. Их среднее (1 + 0 + 2 + 3) / 4 равно 1,5. Для сравнения, в исходном примере MAE составляла 4,0 на тех же четырёх заказах.

Проверка расчёта ошибки (Ответы/01-new-rule.py)

import numpy as np

distances = np.array([1, 2, 4, 5])
actual = np.array([5, 8, 14, 17])
w = 4
b = 0
predictions = w * distances + b
errors = np.abs(predictions - actual)

print("Предсказания", predictions.tolist())
print("Ошибки", errors.tolist())
print("MAE", errors.mean())

Результат

Предсказания [4, 8, 16, 20]
Ошибки [1, 0, 2, 3]
MAE 1.5

Задание 2. Столбец масс

У массива три строки и два столбца. Масса стоит во втором столбце, поэтому её индекс равен 1. Запись features[:, 1] сохраняет все три строки и выбирает из каждой одно число. Средняя масса (1 + 2 + 3) / 3 равна 2 кг. Если выбрать столбец с индексом 0, получится среднее расстояние около 2,33 км.

Выбор столбца по индексу (Ответы/02-weight-column.py)

import numpy as np

features = np.array([[1, 1], [2, 2], [4, 3]])
weights = features[:, 1]

print("Весь массив", features.shape)
print("Столбец", weights.shape)
print("Массы", weights.tolist())
print("Средняя масса", weights.mean())

Результат

Весь массив (3, 2)
Столбец (3,)
Массы [1, 2, 3]
Средняя масса 2.0

Задание 5. Какие строки определяют медиану

Изменяем массу заказа 108, который входит в test. Известные массы в train по-прежнему равны 1, 2, 2, 3, 4 и 6 кг после сортировки. Поэтому медиана train и замена для пропуска в заказе 109 равны 2,5 кг. При объединении выборок известные массы идут в порядке 0,25, 0,5, 1, 2, 2, 3, 4 и 6. Два средних значения равны 2. Для заполнения берём 2,5, рассчитанные на train.

В листинге присваивание через loc меняет массу в таблице в памяти. Сравнение order_id с числом 108 выбирает нужную строку, а weight_kg указывает столбец. Для выделения заказа 109 применяем маску к заполненному столбцу масс и превращаем результат в список из одного числа.

Проверка влияния тестовой строки (Ответы/05-median-check.py)

import pandas as pd

raw = pd.read_csv("delivery.csv")
raw.loc[raw["order_id"] == 108, "weight_kg"] = 0.25
labelled = raw.drop_duplicates().dropna(subset=["price"])
train = labelled.loc[labelled["split"] == "train"]
test = labelled.loc[labelled["split"] == "test"]

median = train["weight_kg"].median()
filled = test["weight_kg"].fillna(median)
print("Медиана train", median)
print("Масса 109", filled.loc[test["order_id"] == 109].tolist())
print("Общая медиана", labelled["weight_kg"].median())

Результат

Медиана train 2.5
Масса 109 [2.5]
Общая медиана 2.0

Задание 6. Границы масштаба

В train минимум равен 1 км, максимум 6 км. Для трёх километров получаем (3 - 1) / (6 - 1) = 0,4. Если взять максимум по всем строкам с ценой, граница 8 км придёт из test. Получится (3 - 1) / (8 - 1) = 2 / 7, или примерно 0,2857. При работе с новым заказом используем границы 1 и 6, сохранённые при подготовке обучающих данных.

Расчёт по двум наборам границ (Ответы/06-scale-check.py)

import pandas as pd

raw = pd.read_csv("delivery.csv")
labelled = raw.drop_duplicates().dropna(subset=["price"])
train = labelled.loc[labelled["split"] == "train"]
train_distance = train["distance_km"]
all_distance = labelled["distance_km"]
distance = 3

def scale(value, numbers):
    low = numbers.min()
    high = numbers.max()
    return (value - low) / (high - low)

print("По train", round(scale(distance, train_distance), 4))
print("По всем строкам", round(scale(distance, all_distance), 4))

Результат

По train 0.4
По всем строкам 0.2857
