# Материалы к книге «Нейронные сети с нуля»

[Сайт первого тома](https://dan1q-dev.github.io/neurobook-vol1/) с примерами на Python, данными и решениями заданий.

В общем архиве файл «Подробные решения.html» открывается без интернета. Каждый архив главы содержит инструкцию по запуску примеров.

GitHub Pages публикует файлы из ветки `main`. Адрес в печатной книге связан с именем аккаунта и репозитория.
